# 청년의 날 9.19 타이밍 챌린지

> 성남시 청년정책협의체 주최 · 청년의 날(9월 19일) 기념 행사용

청년의 날 당일 날짜(9월 19일)를 목표 시간 9.19초로 옮긴, 태블릿 행사 운영용 단일 도전자형 HTML5 블라인드 타이밍 게임입니다. 설치나 빌드 없이 `index.html`을 열면 실행됩니다.

## 플레이 흐름

1. **도전 시작**을 누르면 3·2·1 카운트다운 직후 계측이 시작됩니다.
2. 5~7초 사이 무작위 시점에 화면이 가려집니다.
3. 9.19초라고 느낄 때 **정지**, 스테이지 탭, `Space` 또는 `Enter`로 멈춥니다.
4. 기록, 목표 오차와 미션을 확인합니다.
5. **바로 다시 도전**으로 설정 화면 없이 반복하거나 **시작 화면**으로 돌아갑니다.

15초가 지나면 자동 종료됩니다. 계측 중 페이지가 비활성화되면 해당 도전은 무효가 되며 즉시 다시 도전할 수 있습니다.

## 점수와 미션

판정과 표시는 모두 1/100초 단위로 버림 처리합니다. 기본 미션은 초 끝자리가 `19`인 기록이며 히든 미션 `9.91`, `9.09`, `9.20`, `7.77`을 유지합니다. 미션은 적중할 때 공개되고 시작 화면으로 돌아갈 때 초기화됩니다.

화면 중앙의 큰 스톱워치 숫자가 핵심입니다. 주변에는 성남시 CI의 파랑·금색을 사용한 잔잔한 파동과 빛 효과만 표시해 시간에 집중할 수 있습니다.

## 조작

| 동작 | 방법 |
| --- | --- |
| 시작 | `도전 시작` 또는 시작 화면의 `Space` / `Enter` |
| 정지 | 큰 `정 지` 버튼, 스테이지 탭, `Space` / `Enter` |
| 재도전 | 결과 모달의 `바로 다시 도전` |
| 전체화면·소리 | 헤더 우측 버튼 |

## 테스트와 리허설

- `index.html?test`: 미션 기록 예약과 즉시 정지 리허설 패널
- `test.html`: 미션 경계 17개 사례와 1~15,000ms 내부 시간 구간 매핑 검증

정지 시각은 입력 이벤트 안에서 `performance.now()`로 즉시 캡처합니다. rAF는 화면 연출에만 쓰며, 중단되더라도 결과 확정 fallback이 동작합니다.

## 롤백을 위해 보관된 비사용 레거시

`assets/seongnam-ci.svg`, `js/core/mascot.js`, 캐릭터 컨테이너, 참가자 설정 UI, 준비 오버레이와 다인 순위 함수는 삭제하지 않았습니다. 현재 정상 사용자 경로와 접근성 트리에서는 사용하지 않으며 기존 localStorage 키도 훼손하지 않습니다.
