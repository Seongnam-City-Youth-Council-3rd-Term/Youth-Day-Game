# 🎡 성남 9.19 룰렛 — 청년의 날 블라인드 챌린지

무대 진행용 단독 HTML5 게임입니다. 성남 미니게임 랜드(`../html5`)의 **행운 룰렛**을
그대로 가져와 성나미 캐릭터와 성남시 컨셉을 유지하고, **9.19초 히든 미션**과
**블라인드(화면 가림) 이벤트**를 결합했습니다.

- 설치·빌드·서버 없이 `index.html` 을 브라우저로 열면 바로 실행됩니다.
- 외부 라이브러리·폰트·이미지 파일 없음 (룰렛·성나미·사운드 전부 코드 생성).
- 아이패드 화면 미러링을 전제로 큰 글씨 · 전체화면 버튼 · 탭/스페이스 조작을 지원합니다.

## 게임 규칙

1. 룰렛은 **정확히 9.19초에 한 바퀴**를 돕니다. 12시 포인터의 금색 `9.19` 표식이 결승선입니다.
2. 처음 몇 초 동안은 스톱워치와 룰렛을 그대로 볼 수 있습니다. (페이스 잡기 구간)
3. **5~7초 사이(기본값·랜덤)** 가 지나면 커튼이 화면 전체를 덮습니다. 가려지기 1초 전에 경고가 뜹니다.
4. 가려진 뒤에는 숫자·룰렛·초 단위 효과음이 모두 사라집니다. 오직 감각으로 **[정지]** 를 누르세요.
5. 정지하는 순간 커튼이 열리며 기록이 공개되고, 룰렛이 멈춘 성남 명소가 함께 표시됩니다.
6. 참가자 전원이 한 번씩 도전한 뒤, **9.19초에 가까운 순서**로 순위가 정해집니다.

기회는 참가자당 **단 한 번**입니다. 15초가 지나면 자동으로 시간 초과 처리됩니다.

## 히든 미션 5종

정지 기록이 아래 값과 일치하면 미션이 **그 자리에서 깜짝 공개**됩니다.
(적중 전까지 미션 보드는 화면에 나타나지 않습니다.)

| 코드 | 종류 | 의미 | 판정 |
| --- | --- | --- | --- |
| `9.19` | 기본 | 9월 19일 청년의 날 | **초 끝자리가 19** (8.19 · 10.19 등 모두 포함) |
| `9.91` | 히든 | 19를 뒤집은 숫자 | 정확히 9.91 |
| `9.09` | 히든 | 9월을 의미하는 숫자 | 정확히 9.09 |
| `9.20` | 히든 | 스무 살, 성인의 시작 | 정확히 9.20 |
| `7.77` | 히든 | 행운의 숫자 777 | 정확히 7.77 |

판정은 **화면에 보인 값(1/100초, 버림)** 그대로 사용합니다. 표시와 판정이 어긋나지 않습니다.
최종 결과 화면에서는 적중되지 않은 미션까지 전부 공개되어 진행자가 설명할 수 있습니다.

## 진행 순서 (무대)

1. **참가자 설정** — 이름 1~6명 입력(기본 3명). `가림 시점` 버튼으로 *5~7초 랜덤 / 5초 고정* 전환.
2. **차례 안내** — 참가자 이름을 크게 띄우고 `준비 완료 · 시작`.
3. **3 · 2 · 1 카운트다운** 후 계측 시작 → 블라인드 → 정지 → 기록 공개.
4. 미션 적중 시 의미 설명 카드가 함께 뜹니다. `다음 참가자` 로 이어서 진행.
5. 전원 종료 후 **최종 결과** — 순위, 공동 순위, `9.19에서 가장 먼 기록` 표시.
   결과창을 닫아도 하단 현황판과 미션 보드에 그대로 남고, `최종 결과 다시 보기` 로 재확인할 수 있습니다.

## 테스트 · 리허설

히든 미션은 손으로 맞히기가 사실상 불가능하므로 두 가지 수단을 넣었습니다.

### 1) 리허설 모드 — `index.html?test`

주소 뒤에 `?test` 를 붙여 열면 화면 맨 아래에 **🧪 리허설 모드** 패널이 생깁니다.
(파라미터 없이 열면 패널은 아예 생성되지 않으므로 무대에서 노출될 일이 없습니다.)

| 버튼 | 동작 |
| --- | --- |
| `9.19` `9.91` `9.09` `9.20` `7.77` | 다음 정지를 그 값으로 **기록하도록 예약** |
| `9.25 (근접)` `8.19 (끝자리 19)` | 미적중·기본 미션 케이스 예약 |
| 입력칸 + `입력값 예약` | 임의의 초(예: `10.19`) 예약 |
| `⏹ 즉시 정지` | 계측 중 그 자리에서 정지 (예약값이 있으면 그 값으로) |
| `해제` | 예약 취소 — 이후에는 실제로 누른 시각이 기록됩니다 |

예약해 두고 **직접 [정지]를 눌러도** 예약값이 기록되므로, 커튼 → 공개 → 미션 설명까지
실제 무대와 완전히 같은 연출을 그대로 확인할 수 있습니다. 예약은 한 번 쓰면 자동 해제됩니다.

### 2) 규칙 검증 페이지 — `test.html`

게임에 실린 판정 함수(`SNM.rules`)를 **사본이 아니라 그대로 호출**해 검사합니다. 브라우저로 열면 바로 결과가 나옵니다.

- 미션별 적중 구간표 (예: `9.91` 은 9.910~9.919초)
- 표시값·미션 판정·명소 케이스 17종 (구간 경계 안팎 포함)
- 룰렛 회전각 ↔ 명소 매핑 전수 검사 (1~15,000ms, 1ms 간격)

## 정확도에 대해

- 정지 시각은 rAF 루프가 아니라 **입력 이벤트 안에서 `performance.now()` 로 즉시 캡처**합니다.
  화면 주사율(16.7ms)에 기록이 끌려가지 않으므로 0ms 적중이 가능합니다.
- 계측 중 다른 화면으로 이동하면 시간이 어긋나므로 **그 차례는 무효 처리** 후 다시 진행합니다.
- 가려진 뒤에는 1초 틱 효과음도 멈춥니다. 소리로 초를 세는 것을 막기 위한 설계입니다.

## 커스터마이즈

`js/game.js` 상단 상수만 고치면 됩니다.

```js
var TARGET_MS   = 9190;   // 목표 시각 (룰렛 한 바퀴와 동일)
var BLIND_MIN   = 5000;   // 랜덤 가림 시점 하한
var BLIND_MAX   = 7000;   // 랜덤 가림 시점 상한
var BLIND_FIXED = 5000;   // 고정 모드 가림 시점
var AUTO_STOP   = 15000;  // 자동 시간 초과
var MAX_PLAYERS = 6;      // 최대 참가 인원
```

미션 문구·판정값은 같은 파일의 `MISSIONS` 배열, 룰렛 명소는 `SEGMENTS` 배열에 있습니다.
`SEGMENTS` 는 시간 순서(0번 명소가 0초 지점)이며 8칸 기준으로 계산합니다.
